# 수담 오목

PC와 모바일 브라우저에서 닉네임으로 접속해 친구와 실시간으로 대국하는 15×15 오목 사이트.

- 설계: `docs/superpowers/specs/2026-11-20-omok-arena-design.md`
- 계획: `docs/superpowers/plans/2026-11-20-omok-arena.md`

## 로컬 실행

```bash
npm install
npm run dev          # http://localhost:3000 (Redis 없이 메모리 저장소)
npm test             # 렌주 판정·게임·API 통합 테스트
npm run e2e -- http://localhost:3000   # PC+휴대폰 두 브라우저 시나리오 (Chrome 필요)
```

## 배포 (Vercel + Upstash Redis)

```bash
vercel integration add upstash/upstash-kv --name omok-redis   # 처음 한 번, 약관 동의 필요
vercel deploy --prod
```

**공개 주소: https://omok-arena-dun.vercel.app** (가입 없이 접속, HTTPS)

초대 링크 형식: `https://omok-arena-dun.vercel.app/?room=<방 ID>`

## 기능

- 로비: 닉네임, 방 만들기(렌주룰/자유룰, 한 수 시간제한 없음·30초·60초, 비밀번호를 거는 비밀방), 열린 방 목록(비밀방은 🔒 표시), 초대 링크
- 비밀방: 대국자·관전자 모두 비밀번호를 맞혀야 입장(초대 링크로 와도 동일), 이미 들어온 사람은 새로고침해도 다시 묻지 않음, 비밀번호는 서버에 해시로만 저장
- 대국: 서버 판정(렌주 금수 3·3, 4·4, 장목과 이유, 흑 첫 수 중앙), 최근 착수, 금수 ×, 휴대폰은 고른 뒤 확인 버튼으로 착수
- 시간제한: 차례마다 카운트다운, 시간을 넘기면 서버가 시간패 처리
- 끝난 뒤: 승리 인장, 재대결 요청(상대 화면에 수락/거절, 수락 시 흑백 교대), 기권, 나가기
- 함께 보기: 관전(자리가 차면 자동), 관전자 목록, 대국자 접속 상태(자리 비움), 이모티콘 6종(관전자도 가능, 2초에 1번)
- 방장: 상대 내보내기(대국 중에는 상대가 45초 이상 자리를 비웠을 때만). 내보낸 사람은 그 방에서 관전만 가능
- 새로고침·재접속하면 원래 자리로 복귀
- 나가기: 화면 오른쪽 위 `방 나가기`(로고·뒤로 가기도 같음). 대국 중이면 기권 확인 후 나감. 마지막 사람이 나가면 방이 바로 사라짐
- 방 목록: 앉아 있는 사람이 최근 2분 안에 접속해 있던 방만 보임. 탭을 닫고 10분이 지난 대기 방은 새로 들어올 수 없음. 방 기록은 마지막 활동 2시간 뒤 자동 삭제

## 관리자 페이지

주소: https://omok-arena-dun.vercel.app/admin (검색엔진 수집 안 함)

- 접속 기록: 시각, 종류(방 만들기·입장·재접속·입장 실패·나가기·내보내기·기권·재대결·대국 시작/종료), 닉네임, 방, IP, 지역, 기기
  - IP·방을 누르면 그 조건으로 걸러 보기, 각 줄의 `차단`으로 바로 IP 차단
- 오늘 숫자(접속 IP, 닉네임, 만든 방, 끝난 대국), 지금 있는 방 목록, 차단 IP 목록과 해제
- 기록은 Redis에 7일 보관 후 자동 삭제. 메인 화면 하단에 보관 안내 표시
- 차단된 IP는 방 목록·만들기·입장 등 모든 게임 요청에서 403
- 계정은 Vercel 환경변수(`ADMIN_ID`, `ADMIN_PASSWORD`, 서명 키 `ADMIN_SECRET`, 모두 Sensitive)에만 있고 코드에는 없음
  - 비밀번호 변경: Vercel 프로젝트 Settings → Environment Variables에서 `ADMIN_PASSWORD` 수정 후 다시 배포
- 로그인 12시간 유지, 같은 IP에서 15분에 10번 틀리면 잠시 막힘

```bash
ADMIN_ID=<아이디> ADMIN_PASSWORD=<비밀번호> node tests/e2e-admin.mjs https://omok-arena-dun.vercel.app
```

## 진행 상태

- 완료: 렌주 판정, 방·좌석·재접속, API·SSE, 반응형 화면, Upstash Redis 연결, Vercel 배포
- 검증 (2026-11-20)
  - 로컬: 단위·통합 테스트 57개 통과
  - 공개 주소: PC + 휴대폰(iPhone 13 에뮬레이션) + 관전 브라우저 e2e 35개 통과
    (방 생성, 링크 입장, 착수 동기화, 첫 수 중앙, 3·3 금수 이유 표시, 새로고침 복귀, 기권, 재대결 요청·수락,
    이모티콘, 관전자 표시, 시간제한 카운트다운, 비밀방 비밀번호 확인·오답 거절, 자유룰 5목 승리, 내보내기, 방 나가기·로고·뒤로 가기 처리, 나간 방 목록·링크 정리, 로비 목록)
  - 공개 주소: 관리자 페이지 e2e 11개 통과(로그인, 기록, 방 목록, 걸러 보기, 차단·해제, 로그아웃)
  - 공개 주소: 한 수 30초 방에서 시간을 넘기면 `흑 시간 초과`로 끝나는 것 확인
  - 실제 Upstash Redis에서 중복 방 생성·동시 착수가 한 번만 반영되는지 확인
- 남은 확인: 실제 휴대폰을 LTE 등 다른 네트워크에 두고 PC와 같은 방에서 한 판 두기
  (위 e2e는 이 PC에서 공개 주소로 접속한 것이라, 서로 다른 실제 네트워크 조합은 아직 안 해 봄)
